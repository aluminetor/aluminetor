## `> ls ./featured_projects`

### 01. AegisTrace — API Observability

**Python · FastAPI · SQLite WAL · DuckDB · AsyncIO · AI**

Observability system for Python APIs featuring ASGI request instrumentation, statistical anomaly detection, persistent incident deduplication, and optional AI-assisted diagnostics.

[![AegisTrace](https://img.shields.io/badge/VIEW_PROJECT-AegisTrace-22D3EE?style=for-the-badge&labelColor=0A101F&logo=github)](https://github.com/aluminetor/AegisTrace)

### 02. NetOps Mini — Network Monitoring

**Python · FastAPI · SQLite · Streamlit**

A lightweight network monitoring system that simulates site connectivity metrics, automatically generates incident tickets, prevents duplicate open incidents, and provides an interactive dashboard.

[![NetOps Mini](https://img.shields.io/badge/VIEW_PROJECT-NetOps_Mini-A78BFA?style=for-the-badge&labelColor=0A101F&logo=github)](https://github.com/aluminetor/netops-mini)

### 03. AgentBootDev — Coding Agent

**Python · OpenRouter · AI Agents**

A command-line coding agent that can inspect directories, read and write files, and execute Python scripts using an LLM-powered tool loop.

[![AgentBootDev](https://img.shields.io/badge/VIEW_PROJECT-AgentBootDev-10B981?style=for-the-badge&labelColor=0A101F&logo=github)](https://github.com/aluminetor/agentbootdev)

### 04. MyStudyDiary — Learning Tracker

**JavaScript · HTML · CSS**

A lightweight, local-first web application to log study sessions, track streaks, and visualize learning consistency without external dependencies.

[![MyStudyDiary](https://img.shields.io/badge/VIEW_PROJECT-MyStudyDiary-22D3EE?style=for-the-badge&labelColor=0A101F&logo=github)](https://github.com/aluminetor/MyStudyDiary)
